Castles in Spain

Object

Move all cards to the foundations.

Rules

The piles build down by alternate color. Only one card can be moved at a time, and empty piles can be filled with any card. If there are empty piles, a sequence can be moved too: you can move as many cards as you could move one at a time by using the empty piles for temporary storage (two cards with one empty pile, four with two, and so on).
