Beleaguered Castle

Object

Move all cards to the foundations.

Rules

At game start the four Aces are dealt to the foundations.

The eight piles build down by rank regardless of suit. Only one card can be moved at a time and empty piles can be filled with any single card. If there are empty piles, a sequence can be moved too: you can move as many cards as you could move one at a time by using the empty piles for temporary storage (two cards with one empty pile, four with two, and so on).

Strategy

Build evenly on to foundations. Try to get an empty pile.
